# number-stats-calculator
Console app that calculates sum, average and max of entered numbers

A simple Python console program. The user enters numbers one by one, and the program calculates their sum, avereage and maximum. Results are saved to 'result.txt' file.

## Features 
- input validation (non-numeric input doesn't crush the program)
- handles empty input
- saves results to a file

### How to run
      python main.py

Typee 'стоп' to finish entering numbers.
